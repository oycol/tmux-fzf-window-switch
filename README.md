# tmux-fzf-window-switch

[![CI](https://github.com/oycol/tmux-fzf-window-switch/actions/workflows/ci.yml/badge.svg)](https://github.com/oycol/tmux-fzf-window-switch/actions/workflows/ci.yml)

极速切换 tmux 窗口与会话的终端弹窗。采用通栏输入、左右分栏主体与通栏单行底栏架构，支持全闭环循环导航、S.W 精确定位、无头 fzf 模糊搜索、2D 四方边框网格预览与防连删保护。针对 Tabby 等现代终端深度优化。

## 布局设计

```text
┌─ 窗口切换 · 浏览 ──────────────────────────────────────────────────────────────┐
│ 定位：2.2 / :bios:2       搜索：/                                              │
├─ Session / Window ─────────────────┬─ 预览：bios:2 ────────────────────────────┤
│                                    │                                          │
│   坐标  窗口       路径       Pane  │ debug · 3 panes                          │
│                                    │ ~/company/bios                           │
│ [1] main                           │                                          │
│ * 1.0   shell      ~            1  │ ┌─ 0 bash * ─────────┬─ 1 bash ─────────┐ │
│ - 1.1   editor     ~/src        2  │ │                    │                 │ │
│                                    │ │ $ make test        │ $ git status    │ │
│ [2] bios                           │ │                    │                 │ │
│   2.0   build      ~/bios       1  │ │                    ├─ 2 btop ─────────┤ │
│ > 2.2   debug      ~/bios       3  │ │                    │                 │ │
│   2.3   logs       /var/log     1  │ │                    │ CPU / Memory    │ │
│                                    │ │                    │                 │ │
│                                    │ └────────────────────┴─────────────────┘ │
│                                    │                                          │
│                                    │ 快照 · 布局概览                          │
├────────────────────────────────────┴──────────────────────────────────────────┤
│ j/k窗口  J/K会话  /搜索  Enter切换  Tab上次  ^X删除  ^P预览  ?帮助  Esc退出    │
└───────────────────────────────────────────────────────────────────────────────┘
```

- **顶部输入区**：横跨整个弹窗，明确当前所处模式（`[BROWSE]`、`[SEARCH]`、`[LOCATE]`）。
- **左侧会话框**：仅展示分组标题、精简列（坐标、窗口名、目录路径、Pane数）与状态指示符，**绝不放置帮助信息**。
- **右侧预览框**：窗口详情 Header 与固定 2D 四方边框网格（横向 `─` 与纵向 `│` 分割线齐全，内容不跨 Pane 错位）。
- **底部帮助栏**：**独立、全宽通栏单行**，位于左右主体框下方，中间垂直分割线在帮助栏上方终止。

## 核心特性

- **三种操作模式彻底解耦**：
  - **浏览模式 (BROWSE)**：默认模式，`j/k` 与 `J/K` 快速循环导航；
  - **搜索模式 (SEARCH)**：按 `/` 进入，所有按键（包含 `j`, `k`, `q`）均为搜索文字；`Esc` 退出保留过滤结果；
  - **定位模式 (LOCATE)**：按数字键或 `:` 进入，输入 `2.2` 或 `:bios:2` 锁定唯一目标，`Esc` 取消恢复。
- **闭环循环导航**：
  - `j` / `k`（及 `↓` / `↑`）：在全部可切换窗口间首尾循环（到底部自动回顶部，到顶部自动回底部）；
  - `J` / `K`：在不同 Session 组之间首尾循环，自动跳转每个 Session 的第一个有效窗口。
- **全局唯一 `[-]` 与 Tab 闪跳**：
  - 严格只在当前会话的上次活跃窗口标记 `[-]`；按 `Tab` 精准吸附，多次按不跳到无关窗口。
- **安全销毁与防连删**：
  - 选中目标按 `Ctrl-x` 销毁对应 Window（严禁销毁当前所在窗口）；
  - 销毁后就近吸附，但**自动禁用连续销毁**，必须显式移动光标后才允许再次删除，杜绝按住连删。
- **动态视口自适应**：
  - 超宽屏自动锁定最佳阅读宽度（140~160列），防止视线过度拉扯；纵向高度自适应舒展，告别多余黑屏。

## 依赖

- Python >= 3.8 (标准库 curses)
- tmux >= 3.2
- fzf >= 0.74 (用于高性能后台模糊过滤)

## 安装

### TPM (推荐)

在 `~/.tmux.conf` 中添加：

```tmux
set -g @plugin 'oycol/tmux-fzf-window-switch'
```

按 `prefix + I` 安装，TPM 会自动注册 `prefix + w` 绑定。

### 手动安装

```bash
git clone https://github.com/oycol/tmux-fzf-window-switch ~/.tmux/plugins/tmux-fzf-window-switch
```

在 `~/.tmux.conf` 中追加：

```tmux
run-shell ~/.tmux/plugins/tmux-fzf-window-switch/tmux_fzf_window_switch.tmux
```

## 键位速查

| 键位 | 模式 | 功能 |
| :--- | :--- | :--- |
| `j` / `k` 或 `↓` / `↑` | 浏览 | 下一个 / 上一个窗口（**首尾闭环循环**） |
| `J` / `K` | 浏览 | 下一个 / 上一个 Session 首项（**会话间首尾循环**） |
| `/` | 浏览 | 进入搜索模式（支持输入任何字符，Esc 退出保留过滤） |
| `2.2` / `:name:idx` | 浏览 | 进入定位模式（精准匹配，不混淆 12.2 或 2.20） |
| `Tab` / `Shift-Tab` | 浏览 | **Session 内循环**：在当前光标所在的 Session 内部循环切换窗口（不越界至其他会话） |
| `J` / `K` | 浏览 | **跨 Session 飞跃**：跳转到下一个 / 上一个 Session 的首项（支持首尾循环） |
| `j` / `k` | 浏览 | 逐行移动光标（跳过 Session 标题与当前源窗口，首尾循环） |
| `Enter` | 通用 | 确认切换（若停留在当前源窗口则安全关闭弹窗；默认初始光标为 `[-]` 上次活跃窗口） |
| `Ctrl-x` | 浏览 | 销毁当前选中的非当前窗口（附带防连删保护） |
| `v` | 浏览 | 切换布局概览与单 Pane 详情模式 |
| `[` / `]` | 浏览 | 切换预览不同 Pane |
| `Ctrl-p` | 浏览 | 显隐右侧预览区域 |
| `Ctrl-u` | 浏览 | 清除当前的搜索过滤条件 |
| `?` | 浏览 | 展开 / 关闭完整按键帮助信息 |
| `q` / `Esc` | 浏览 | 退出弹窗 |
